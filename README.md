# ととのい道 (TOTONOI)

サウナ → 水風呂 → 外気浴 を 3 セット繰り返して「ととのう」ことを目指す、[Pyxel](https://github.com/kitao/pyxel) 製のミニゲームです。

## 遊び方

| 操作 | キーボード | スマホ |
|---|---|---|
| A | SPACE / Z | 画面タップ |
| B（でる） | X / ENTER | 右下の「でる」ボタン |

1. **サウナ**: A 長押しで上段（早く温まる＆汗ボーナス）。体温 75〜90 で B を押して退室。100 になるとのぼせる。
   ロウリュ中は、輪が重なった瞬間に A で「ナイス熱波」。
2. **水風呂**: A 連打で呼吸カーソルを緑のゾーンに保つ。2 秒キープで「羽衣」。体温 20〜40 で B。
3. **外気浴**: じっとする。邪魔（蚊・カラス・常連さん・風）が来たときだけ A で追い払う。

## 実行

```bash
pip install pyxel
python main.py
```

ブラウザでは `index.html` を HTTP サーバー経由で開きます（例: `python -m http.server` して http://localhost:8000/ ）。

企画の詳細は [docs/game_design.md](docs/game_design.md) を参照してください。
