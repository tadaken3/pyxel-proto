# ととのい道 ― サウナ × Pyxel 企画書

## 1. コンセプト

> **「サウナ → 水風呂 → 外気浴」の 1 セットを、3 つのミニゲームでそのまま遊ぶ。**

サウナ好きが毎回やっている「どこまで粘るか」「水風呂で呼吸を整える」「外気浴でじっとする」という
駆け引きを、そのままゲームの手触りにする。ゴールは “ととのう” こと。

- ジャンル: リズム／タイミング系ミニゲーム集（1 プレイ 3〜4 分）
- 画面: 192×144、30fps、日本語ビットマップフォント（umplus 10px）
- 操作: **ボタン 2 つだけ**（スマホはタップ＋画面右下の「でる」ボタン）
- 想定プラットフォーム: PC（Pyxel）／ブラウザ（`index.html` で Pyxel Web 実行）

### 方針（Pyxel のユーザー作品・公式サンプルを参考にした点）
- ワンキー〜ツーキーで遊べる短いアーケード作品が Pyxel では映える
  （公式書籍サンプルのワンキー救出ゲームなど）。スマホのタップ対応とも相性が良い。
- 画像リソースに頼らず、図形描画 API とコードで定義した SE / MML の BGM で完結させる
  → 1 ファイルで読みやすく、改造しやすい。
- 画面遷移（タイトル → プレイ → リザルト）をシーンクラスで分ける（公式シューティングサンプルと同じ構成）。

## 2. ゲームの流れ

```
タイトル → [ サウナ → 水風呂 → 外気浴 → セット結果 ] × 3 セット → 最終結果（称号）
```

セットが進むほどサウナが熱くなり、ロウリュや邪魔が増える。

## 3. 操作

| 操作 | キーボード | ゲームパッド | スマホ / マウス |
|---|---|---|---|
| A（アクション） | SPACE / Z | A | 画面をタップ |
| B（でる） | X / ENTER | B | 右下の「でる」ボタン |

## 4. 各フェーズの仕様

### 4-1. サウナ（体温を上げる）
- 体温ゲージ（0〜100）が時間とともに上がる。
- **A を押している間は上段**：上昇速度 2 倍・汗ポイントも多くもらえる。離すと下段。
- **B で退室**。退室時の体温で評価が決まる。
  - 75〜90: ちょうどいい（×1.0） / 90〜100: 攻めた（×1.15）
  - 100 到達: **のぼせ**（強制退室・大幅減点）
- **ロウリュ & 熱波**：熱波師が登場して石に水をかける（体温が急上昇）。
  続いてタオルで 4 回あおぐので、輪が重なった瞬間に A を押すと「ナイス熱波！」で汗ボーナス。
  外すと熱いだけ。
- サウナ室の 12 分計が回る（雰囲気演出）。

### 4-2. 水風呂（体温を下げる・呼吸を整える）
- 体温がサウナから引き継がれ、どんどん下がる。
- 左の「呼吸メーター」でカーソルが沈んでいくので、**A 連打で浮かせて**「落ち着きゾーン」に保つ。
  入水直後はコールドショックでカーソルが暴れる。
- ゾーン外にいると「パニック」が溜まり、満タンで強制退室。
- ゾーン内に 2 秒いると **羽衣** が発動：冷える速度がゆっくりになり、調整しやすくなる。
- **B で退室**。体温 20〜40 で出るのがベスト。冷えすぎ（10 未満）は減点。

### 4-3. 外気浴（ととのう）
- イスに座って 20 秒。**何もしないこと** がメインの操作。
- サウナ・水風呂の評価が良いほど「ととのいゲージ」が早く溜まる。
- 邪魔（蚊・カラス・話しかけてくる常連・強い風）が出たら **A で追い払う**。
  放置すると「ざわざわ…」でゲージが減る。
- **何もいないのに A を押すと「そわそわ」** でゲージが減る（じっとするのが大事）。
- ゲージ 100% で「ととのったー」状態。空の色が変わり、得点が 1.5 倍になる。

### 4-4. 得点・称号
- セット得点 = 外気浴中に毎フレーム `ゲージ% × 0.01`（ととのい中は 1.5 倍）を加算。
- 3 セット合計で称号:
  - 〜299 サウナビギナー / 〜649 サウナ好き / 〜999 サウナー / 〜1349 ととのい職人 / 1350〜 サウナの神

## 5. 画面・演出
- サウナ: 木の壁・3 段ベンチ・ストーブ・12 分計・温度計ゲージ・湯気パーティクル
- 水風呂: 青い水面と波紋、首まで浸かった主人公、羽衣のキラキラ
- 外気浴: 空・雲・木・イス。ととのうほど空がサイケデリックに色づき、光の粒が舞う
- 主人公: サウナハットをかぶった小さな人（図形で描画）

## 6. サウンド
- SE: 決定、ロウリュ（ジュワッ）、熱波ナイス、ミス、水しぶき、ととのいチャイム
- BGM: 外気浴中のゆったりした MML ループ

## 7. 技術構成

```
main.py              ゲーム本体（シーンクラス + 描画ヘルパー）
assets/umplus_j10r.bdf  日本語ビットマップフォント（Pyxel 同梱サンプルと同じもの）
index.html           ブラウザ実行用（Pyxel Web）
docs/game_design.md  この企画書
```

- `Game` がシーンを切り替える。各シーンは `update()` で次のシーンを返すと遷移。
- `Body`（体温・各評価）をシーン間で受け渡す。
- 入力は `inp_a_held / inp_a / inp_b` に集約し、キーボード・パッド・タップを同一視。

## 8. 今後の拡張アイデア
- サウナ施設の選択（ドライサウナ / ボナサウナ / テントサウナ / 薪サウナ）で難易度とルールが変わる

- オロポ購入などのショップ要素、ハイスコアの保存（`pyxel.user_data_dir`）
- ドット絵スプライト（Pyxel Editor で `.pyxres` を作成）への差し替え
